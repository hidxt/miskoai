完整备份 数据库 + 图片

完整数据库与图片备份

下载所有范围的数据库与当前图片内容（最多 321 MiB），包含私密记忆、历史和图片，请妥善保管。用于回退恢复而保留的旧图片不属于当前备份。此文件与仅包含元数据的 SQLite 数据库快照不同。

恢复完整数据库与图片

恢复将替换所有范围的数据库与图片目录，可能回退接收、去重和发送历史。操作前先下载当前完整备份。确认后先停止聊天生成，即使文件校验失败也可能保持停止；服务端先校验再安装。旧内容可能保留用于恢复，不能保证数据库与图片同时完成，也不能保证旧内容全部清除。成功后通道保持暂停，必须人工核对后单独恢复通道。失败、取消等待或结果不明确时，请先刷新诊断、核对实际状态，不要重复提交。

仅数据库 SQLite 快照

一致性数据库快照

下载由服务端准备的 SQLite 数据库快照（最多 256 MiB）。包含图片元数据，不包含二进制图片；恢复元数据后可能需要完整内容恢复。请妥善保管。

恢复数据库

恢复将替换当前数据库，二进制图片不在此快照中；旧图片内容保留，元数据可能需要完整内容恢复。旧数据库快照可能回退接收与去重历史；恢复后通道保持暂停，必须人工核对后单独恢复通道。操作前先下载当前数据库快照。
