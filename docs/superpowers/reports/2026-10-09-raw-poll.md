## Behavior and implementation decisions

`RawUpdates(ctx, cursor)` performs exactly one authenticated bounded poll. It shares the original transport, header construction, poll slot, cancellation/deadline and response read with `GetUpdates`, preserves the 40-second poll deadline and 2 MiB cap, and makes no retry. One outbound/login slot remains independent of the poll slot. Login/send continue through the typed wrapper over that same exchange; the 15-second send deadline and ambiguous-send sentinel handling remain in place.

Successful malformed response bodies, including invalid UTF-8, primitive/null outer values and invalid typed message content, are returned byte-for-byte from raw polling. The classifier only rejects well-formed explicit business failures; malformed status/JSON is retained for caller-owned durable quarantine. HTTP/transport/size failures retain safe sentinel errors. Remote error text is never included in an error.

`DecodeUpdates` checks the body cap, UTF-8, outer object, valid complete JSON and `ret`/`errcode` before decoding typed content. Either field reporting -14 takes precedence over another nonzero generic service failure, so runtime account cancellation cannot be masked. Root requested this pinned-guard classification correction after inspecting the shared helper; it does not establish the cause of any original live failure. Absent/null `msgs` represents an empty batch; primitive/object `msgs` and non-object message/item elements fail with `ErrProtocol`. Unknown fields remain accepted.

The decoder walks each object through `json.Decoder` and raw fields, then walks array elements one at a time. It never preflights into `[]Message`, `[]Item`, `[]any` or a map containing an arbitrary message array. Only after preflight succeeds does typed JSON unmarshal run. Each updates object has one cumulative budget of 256 messages across matching duplicate `msgs` keys; each message object has one cumulative budget of 256 items across duplicate `item_list` keys. Every earlier duplicate is checked even if later overwritten. Matching uses `strings.EqualFold` to mirror encoding/json, including Unicode long-s variants; simple lowercasing would allow a typed-array allocation bypass.

Cursor and all known message/item identifiers/context/session/group/user fields are bounded to 16 KiB. Text is bounded to 16 KiB. Known opaque media/reference raw fields are bounded to 16 KiB in encoded JSON form. The existing lossless top-level and item ID decoding is preserved. Unknown fields may occupy the bounded response but do not create unbounded typed slices. Preflight can copy raw field/element bytes; this is a response-bounded design, not a zero-copy or RSS claim.
