# Foundation implementation plan

> For agentic workers: use superpowers:executing-plans for primary implementation and explicitly scoped Medium research/review tasks. User master task authorizes autonomous routine execution.

**Goal:** build and verify Phase0 foundation and Phase1 protocol/provider/storage PoCs.
**Architecture:** Go modular monolith, narrow HTTP/provider/channel/storage interfaces. No extra resident runtime.
**Tech stack:** Go 1.27, net/http, encoding/json, database/sql, candidate modernc.org/sqlite.
**Spec:** docs/superpowers/specs/2026-10-09-phase0-1-design.md and REQUIREMENTS.md.

## Global constraints
Brand MiskoAI, module github.com/hidxt/miskoai, Linux amd64/arm64, SQLite, DeepSeek/Ollama official cloud, target 2 vCPU / 512MB. No containers/WSL/local model. Secrets never published. Children only GPT-6.1 Medium. No invented live tests.

## Review focus
- Oversized/truncated remote payload: fail with safe error and bounded allocation.
- Cross-account user facts: never return or mutate another scope.
- Duplicate delivery/crash after send: preserve durable state; no blind resend.
- Endpoint redirect/private destination: reject without forwarding bearer credentials.
- Chinese facts and expired facts: scoped keyword fallback and expiry filtering.
